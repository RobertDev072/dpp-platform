# Juridische documenten VeriPasso (CONCEPT)

Stand: 2026-10-20. **Alles hier is een concept en geen juridisch advies.** De teksten zijn
opgesteld uit de feitelijke werking van de software en infrastructuur. Laat ze vóór publicatie
controleren door een jurist. Alles tussen `[INVULLEN: …]` vult de eigenaar aan; keuzes die nog
een besluit vragen staan als `[BESLUIT: …]`.

| Document | Voor wie | Publiceren? |
|---|---|---|
| [privacyverklaring.md](privacyverklaring.md) | iedereen (website, app, paspoortpagina) | ja, als pagina `/privacy` |
| [algemene-voorwaarden.md](algemene-voorwaarden.md) | zakelijke klanten en partners | ja, als pagina `/voorwaarden`, en meesturen bij een offerte |
| [verwerkersovereenkomst.md](verwerkersovereenkomst.md) | zakelijke klanten (VeriPasso verwerkt namens hen) | bij elk klantcontract |
| [subverwerkers.md](subverwerkers.md) | klanten, intern | ja (lijst), plus interne controle van leveranciersvoorwaarden |
| [bewaartermijnen.md](bewaartermijnen.md) | intern, samenvatting in privacyverklaring | intern |
| [datalekprocedure.md](datalekprocedure.md) | intern | intern |
| [verwerkingsregister.md](verwerkingsregister.md) | intern (AVG art. 30), op verzoek aan de AP | intern |
